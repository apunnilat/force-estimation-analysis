# Results

The two commands write their outputs here by default:

- `thesis_results/`: `python results_report.py`
- `thesis_diagnostics/`: `python diagnostics_report.py`

Only the final versions used in the thesis are committed. Each output folder
contains `run_info.json`, which records the settings, the input files (with
SHA-256 checksums), the git commit and the package versions that produced it.
